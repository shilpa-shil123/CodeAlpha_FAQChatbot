🌐 Language Translation Tool with FAQ Chatbot

📌 Project Overview

The Language Translation Tool is a web application developed using Python and Streamlit. It allows users to translate text between different languages through a simple and user-friendly interface.

The application also includes an FAQ Chatbot that answers frequently asked questions about the translation tool and helps users understand how to use it.

✨ Features

- 🌍 Translate text between supported languages.
- 📝 Simple and user-friendly interface.
- 💬 Interactive FAQ Chatbot.
- ❓ Answers common questions about the application.
- ⚡ Quick and convenient translation.
- 💻 Web-based application accessible through a browser.

🛠️ Technologies Used

- Python – Programming language.
- Streamlit – Web application framework.
- Deep Translator – Translation library.
- GitHub – Source code management.
- Streamlit Community Cloud – Application deployment.

⚙️ Installation and Setup

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the Project Folder

cd CodeAlpha_LanguageTranslationTool

3. Install the Required Libraries

pip install -r requirements.txt

4. Run the Application

streamlit run app.py

The application will open in your browser.

💬 FAQ Chatbot

The FAQ Chatbot helps users find answers to common questions, including:

- What is this tool?
- How do I translate text?
- Which languages are supported?
- Is the tool free?
- What should I do if translation is not working?

The chatbot uses predefined questions and keyword matching to provide answers.

🚀 Deployment

The application can be deployed using Streamlit Community Cloud and connected to a GitHub repository.

🎯 Project Objective

The objective of this project is to develop a simple and accessible language translation application while demonstrating the use of Python libraries, web application development, and basic chatbot functionality.
